# Bridging Education Industry Skill Gap

This Python script simulates the skill gap between education and industry. It defines required industry skills and graduate-possessed skills, then calculates and reports the difference (the gap) for each graduate.

## Language

`python`

## How to Run

Save the code as `skill_gap_simulation.py` and run it from your terminal using `python skill_gap_simulation.py`.
